# MiniModel Evidence And Claim Boundary

Keep these claims separate:

- metadata published;
- source and license bound;
- composition structurally accepted;
- numerical parity passed;
- behavior qualified;
- peer currently available;
- transfer completed;
- browser activated;
- site deployed; and
- public HTTPS bytes verified.

No earlier claim implies a later one. Source, configuration, package creation,
fixtures, mocks, localhost, LAN probes, or endpoint reachability are not live
production proof.

Public-safe evidence may include exact schema/profile identities, source
revision, cryptographic digests, bounded sizes and counts, typed statuses,
resource summaries, and receipt identities. It excludes prompts, raw outputs,
model bytes, credentials, invitation URLs, local paths, and raw private
evidence.

The current campaign counters remain:

- `0/20` qualified models;
- `0/50` clean browser rounds;
- `0/25` live memory rounds;
- `0/40` externally proven P2P lanes; and
- `0/20` catalog announcements.

Only exact matching live receipts may change those counters.
