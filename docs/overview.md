# MiniModel Current Protocol Overview

MiniModel.org is the metadata catalog and discovery surface for exact qualified
SLM2 compositions. MiniModel.MiRust.com is its prelaunch developer and protocol
documentation site.

Project sites do not host, proxy, convert, or execute model bytes. They do not
receive prompts. Catalog metadata can identify a candidate route, but cannot by
itself prove qualification, current peer availability, transfer, installation,
browser execution, publication, or campaign progress.

## Current Acquisition Contract

1. Resolve one exact catalog identity.
2. Prefer one exact currently qualified composition offered by a consenting
   peer.
3. If that exact route is unavailable, require explicit user approval for an
   installed local companion to acquire one immutable public source revision
   and perform one registered conversion.
4. Independently verify source, license, provenance, composition closure,
   member identities, qualification references, and runtime profile.
5. Atomically install only the complete accepted six-member composition.
6. Open the installed composition in TinyRustLM.com.

The product does not silently switch routes, select a different peer, invoke
remote inference, download an instruction file, repair evidence, or retry a
failed operation invisibly.

## SLM2 Composition

A current composition is exactly:

- `model.slm2`
- `tokenizer.tokenizer2`
- `template.template2`
- `sampling.sampling2`
- `prompt.prompt2`
- `composition.acg2`

Old `.slm`, manifest-v0, verifier-MVP, script-handoff, alias, compatibility,
migration, and fallback paths are not current.

## MemoryEndpoints.com

MemoryEndpoints.com has exactly two separate ecosystem uses:

1. Agents working across all maintained sites use it directly for
   agent-to-agent long-term memory, meetings, handoffs, and coordination.
2. Separately, a TinyRustLM.com Connect user signs in to MemoryEndpoints.com
   and explicitly selects it as TinyRustLM.com Connect long-term memory.

The two lanes keep identity, credentials, consent, scopes, provenance,
idempotency, and receipts separate. MemoryEndpoints.com is not MiniModel model
transport, catalog, peer relay, conversion, or inference infrastructure.

Prelaunch memory may also be duplicated in current `.uai`, wiki, public-safe
source notes, and approved private stores. Every maintained copy must stay
current, secret-safe, provenance-labeled, and noncontradictory.

## Current Proof Status

Configuration, fixtures, mocks, local probes, and reachable endpoints are not
live proof. Campaign counters remain `0/20`, `0/50`, `0/25`, `0/40`, and
`0/20` until exact matching receipts exist.
